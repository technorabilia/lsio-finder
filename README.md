# lsio finder

A searchable catalog of [LinuxServer.io](https://www.linuxserver.io/) Docker apps. Find any of 200+ apps by name, category or port, and copy a ready-to-use Docker Compose file, `docker run` command or setup script in one click. The configs load live from [technorabilia/docker-bits](https://github.com/technorabilia/docker-bits), so new apps appear automatically.

**Open the site:** https://technorabilia.github.io/lsio-finder/
